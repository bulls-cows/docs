# 处理易过时联系方式信息的计划

## 问题分析

在 `c:\workspace\develop\docs\docs\06-listening-world\03-treatment\02-shanghai-sunshine-baby.md` 文件的第144-163行，包含了上海各区残疾人联合会的具体地址和联系电话表格。此外，第165-170行还包含了市级残联的具体地址和电话。

**问题点**：

1. 政府部门的地址、电话可能随时间变更（搬迁、机构调整等）
2. 纸质/电子图书更新周期长，信息容易过时
3. 过时的联系方式可能误导读者
4. 维护这类信息增加了内容维护负担

## 处理方案

### 1. 删除具体的地址和电话表格

* 移除第144-163行的各区残联地址电话表格

* 移除第167-169行的市级残联具体地址和电话

### 2. 保留官网信息，引导读者查询最新联系方式

* 保留上海市残联官网链接

* 增加说明文字，指导读者如何获取最新联系方式

* 强调"以官方最新信息为准"的原则

### 3. 优化后的内容结构

将"办理地点和联系方式"章节改为：

```markdown
## 办理地点和联系方式

### 查询最新联系方式

各区残疾人联合会（残联）的具体地址和联系电话可能随时间变化，建议通过以下方式获取最新信息：

1. **访问上海市残疾人联合会官网**：[http://www.shdpf.org.cn](http://www.shdpf.org.cn)
2. **拨打全市统一服务热线**：12385（全国残疾人服务热线）
3. **查询各区政府官方网站**：搜索"XX区残疾人联合会"获取最新联系方式

### 办理流程提示

- 申请需向**户籍所在区残联**提交材料
- 建议办理前先通过官网或电话确认最新政策和办理要求
- 市级主管部门：上海市残疾人联合会
```

### 4. 更新 AGENTS.md 写作规范

在 `AGENTS.md` 的"写作规范"章节中添加"易过时信息处理原则"：

```markdown
### 易过时信息处理原则

#### 避免在图书内容中包含以下易过时信息：
- 政府部门、机构的具体地址、联系电话
- 特定版本号、价格信息（除非是历史数据或明确标注时间戳）
- 临时政策细节（可能随时间变化的具体规定）

#### 处理方式：
1. **优先提供官方渠道信息**：官网链接等
2. **引导读者查询最新信息**：说明信息可能变化，建议查询官方渠道
3. **明确标注信息获取方式**：告诉读者如何获取最新信息
4. **保留时间戳**：如必须包含时效性信息，应明确标注发布时间或有效期
```

### 5. 检查全书其他类似内容

* 搜索整个书籍目录，检查是否有其他包含具体地址、电话等易过时信息的地方

* 统一采用相同的处理原则

## 执行步骤

1. 编辑 `02-shanghai-sunshine-baby.md` 文件，修改"办理地点和联系方式"章节
2. 搜索全书，检查是否有其他类似的易过时联系方式信息
3. 将处理易过时信息的原则总结到 `AGENTS.md` 的写作规范中
4. 执行 `npm run lint` 确保文档格式正确
5. 预览修改效果

## 预期效果

* 减少书籍中的易过时信息，降低维护成本

* 引导读者通过官方渠道获取最新信息，确保信息准确性

* 保持书籍内容的实用性和指导性，避免因信息过时而失效
