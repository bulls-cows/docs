# 添加文档更新原则到 Quality Gate

## 任务目标
在 AGENTS.md 的 Quality Gate 中添加文档更新原则，提示AI在改动后需要判断是否需要更新 AGENTS.md 和 README.md。

## 具体修改方案

### 修改 AGENTS.md 的 Quality Gate 部分

#### 当前内容：
```
## Quality Gate

改动后必须执行: `npm run lint`
```

#### 修改为：
```
## Quality Gate

改动后必须执行:

1. 判断是否需要更新以下文档，如需要则按对应原则更新：

   - **AGENTS.md**（面向AI编程大模型）：
     - 当项目范围、目录结构、规范、命令、提交规则、注意事项等发生变化时需要更新
     - 更新原则：只包含AI需要的指令和规范，移除面向人类读者的冗余说明文字，保持简洁清晰

   - **README.md**（面向图书阅读者）：
     - 当项目介绍、核心内容、特色亮点、技术栈、联系方式等发生变化时需要更新
     - 更新原则：对普通读者友好，不包含技术性配置和命令（如版本号、构建命令、开发步骤等），保留核心内容

2. `npm run lint` - 执行完整检查
```

## 验证标准
- ✅ Quality Gate 中明确包含了两个文档的更新触发条件和原则
- ✅ 文档判断在前，npm run lint 在后
- ✅ 内容简洁清晰，符合 AGENTS.md 面向AI的风格
- ✅ npm run lint 验证通过
