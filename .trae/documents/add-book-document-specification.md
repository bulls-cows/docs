# 补充书籍文档命名与 frontmatter 规范的计划

## 现状分析

- 现有 "写作规范" 章节包含了部分 frontmatter 说明，但主要针对一般文档
- 缺少针对**书籍类文档**（书籍根目录 + 其所有层级子目录）的专门命名规范

## 术语定义

**书籍类文档**：指整个书籍目录树，包括：
- **书籍根目录**：含有 `toc.md` 文件的目录（如 `05-health-handbook/`）
- **书籍子目录**：书籍根目录下的所有层级子目录（篇、章等）

### 新增：书籍文档命名规范

书籍类文档采用严格的层级命名体系，文件名直接影响侧边栏显示顺序。

#### 1. 术语定义

| 术语 | 定义 | 识别方式 |
|------|------|---------|
| 书籍根目录 | 书籍的最顶层目录 | 目录内包含 `toc.md` 文件 |
| 书籍子目录 | 书籍根目录下的所有层级子目录 | 位于书籍根目录树内的任意子目录 |
| 书籍类文档 | 整个书籍目录树 | 书籍根目录 + 其所有层级子目录 |

#### 2. 书籍根目录文件

位于书籍根目录下的文件：

| 文件 | 命名格式 | 说明 | 侧边栏位置 |
|------|---------|------|-----------|
| 书籍首页 | `index.md` | 固定文件名，内容为前言或简介 | 固定第1位，显示为"前言" |
| 目录页 | `toc.md` | 固定文件名，内容为目录结构 | 固定第2位，显示为"目录" |
| 附录/术语表 | `99-xxx.md` | 推荐使用 90+ 序号前缀 | 按序号排在所有章节之后 |
| 其他独立文件 | `NN-xxx.md` | 使用两位数字序号前缀 | 与子目录统一排序 |

**书籍根目录侧边栏排序逻辑**：
- 前言（index.md）→ 目录（toc.md）→ 其他所有文件和子目录**统一按序号排序**
- 不区分是独立文件还是子目录，仅看序号前缀大小
- 示例：`99-glossary.md`（序号99）会排在 `06-prevention/`（序号6）之后

#### 3. 篇目录（书籍根目录下的第一层级子目录）

对应书籍的"篇"，如"第一篇 内科系统"：

- 命名格式：`NN-篇英文名/`
- 序号范围：01~89（预留 90+ 给附录）
- 示例：
  - `01-internal-medicine/` - 第一篇 内科系统
  - `02-surgery/` - 第二篇 外科系统
  - `06-prevention/` - 第六篇 预防保健

**目录内必须包含**：`index.md`（该篇的首页）

**篇目录侧边栏排序逻辑**：
- 先显示该目录内的独立 Markdown 文件（按序号排序）
- 后显示该目录内的子目录（按序号排序）

#### 4. 章目录（篇目录下的子目录）

对应书籍的"章"，如"第一章 心血管"：

- 命名格式：`NN-章英文名/`
- 序号范围：01 开始递增
- 示例：
  - `01-cardiovascular/` - 第一章 心血管
  - `02-respiratory/` - 第二章 呼吸

**章目录侧边栏排序逻辑**：与篇目录相同，先文件，后子目录

#### 5. 节文件（章目录下的 Markdown 文件）

对应书籍的"节"，直接放在章目录下：

- 命名格式：`NN-节英文名.md`
- 序号范围：01 开始递增
- 示例：
  - `01-diagnosis.md` - 第一节 诊断
  - `02-treatment.md` - 第二节 治疗

#### 6. 排序规则总结

| 目录层级 | 排序规则 | 示例 |
|---------|---------|------|
| 书籍根目录 | 前言 → 目录 → 所有文件/子目录**统一按序号排序**（不区分类型） | `index.md` < `toc.md` < `01-xxx/` < `02-xxx.md` < `99-xxx.md` |
| 书籍子目录（篇/章） | 先独立文件（按序号），后子目录（按序号） | `01-xxx.md` < `02-xxx.md` < `01-xxx/` < `02-xxx/` |
| 普通文档目录 | 同书籍子目录规则 | - |

> **重要提示**：仅在书籍根目录层级，独立文件与子目录会混合排序，仅比较序号前缀。其他所有层级目录均按"先文件，后目录"排序。

### 完善：Frontmatter 撰写规范

在现有 "Frontmatter 约定" 基础上，补充书籍文档的特殊要求：

```markdown
### Frontmatter 撰写规范（完善版）

不同类型的文件有不同的 frontmatter 要求：

| 文件类型 | 必需字段 | 可选字段 | 说明 |
|---------|---------|---------|------|
| docs 根目录下的 .md 文件（非 index.md） | 无 | title | - |
| 第一层子目录的 index.md | shortTitle | title | 文件夹名需以两位数字序号开头（如 01-book-name） |
| 书籍根目录的 index.md | shortTitle | title | 侧边栏显示为"前言"，不使用 title 字段 |
| 书籍 toc.md | 无 | 无 | 侧边栏显示为"目录" |
| 篇目录的 index.md | 无 | title | title 为该篇的显示名称 |
| 章目录的 index.md | 无 | title | title 为该章的显示名称 |
| 节文件（.md） | 无 | title | title 为该节的显示名称 |
| 其他目录的 index.md | 无 | title | - |
| 其他 .md 文件 | 无 | title | - |

#### 字段说明

- `title`: 侧边栏显示标题。未填写时从文档一级标题或文件名自动提取
- `shortTitle`: 导航栏短标题，用于顶部导航（仅第一层子目录 index.md 需要）
- `sidebar`: 设为 `false` 可隐藏侧边栏显示

#### 书籍文档 frontmatter 示例

**书籍根目录 index.md**（前言页）：
```yaml
---
shortTitle: 健康科普
title: 健康科普手册
---
```

**篇目录 index.md**：
```yaml
---
title: 内科系统
---
```

**节文件**：
```yaml
---
title: 诊断方法
---
```
```
