# 补充 AGENTS.md 排序说明的计划

## 现状分析

检查 `AGENTS.md` 文件后，发现以下与排序相关的现有内容：

### 已有说明：
1. **文件夹命名规范**（第 76-79 行）：
   - 第一层子目录需以两位数字序号开头（`NN-name` 格式）
   - 序号作用：决定板块在**导航栏**的显示顺序

2. **侧边栏自动生成说明**（第 192 行）：
   - 侧边栏由目录结构自动生成（通过 `config/.vitepress/sidebar.ts`）

### 缺失的重要说明：

1. **侧边栏排序的核心逻辑**：
   - 侧边栏项如何按文件名/目录名的两位数字前缀排序
   - `order` 字段的提取和使用规则

2. **书籍根目录的特殊排序逻辑**（本次修复的内容）：
   - 前言（index.md）固定在第一位
   - 目录（toc.md）固定在第二位
   - 其他独立文件和子目录合并后，统一按序号前缀排序（不区分类型）

3. **非根目录的排序逻辑**：
   - 先显示独立 Markdown 文件，后显示子目录

4. **附录类文件的命名建议**：
   - 如何通过序号前缀（如 `99-`）控制附录显示在最后

## 补充方案

在 `AGENTS.md` 的"注意事项"部分之前，新增"侧边栏排序规范"章节，包含以下内容：

### 新增章节内容大纲：

```markdown
## 侧边栏排序规范

侧边栏配置由 `config/.vitepress/sidebar.ts` 自动生成，遵循以下排序规则：

### 1. 排序依据

所有侧边栏项（文件和目录）均按名称中的**两位数字前缀**确定排序优先级：
- 格式：`NN-filename.md` 或 `NN-directory-name`
- 示例：`01-internal-medicine`（order=1）、`99-glossary.md`（order=99）
- 无前缀的项默认排在最后（order=Number.MAX_SAFE_INTEGER）

### 2. 书籍根目录（含 toc.md 的目录）特殊规则

对于书籍类目录（如 `05-health-handbook/`），显示顺序为：

| 顺序 | 内容 | 来源 | 说明 |
|------|------|------|------|
| 1 | 前言 | index.md | 固定第一位，标题强制显示为"前言" |
| 2 | 目录 | toc.md | 固定第二位，标题强制显示为"目录" |
| 3+ | 其他内容 | 其他 .md 文件和子目录 | 统一按序号前缀排序，**不区分是文件还是目录** |

**示例**：`99-glossary.md`（附录）会排在 `01-xxx/` ~ `06-xxx/` 所有子目录之后。

### 3. 非根目录规则

子目录内部（非书籍根目录）的显示顺序为：
1. 先显示该目录下的独立 Markdown 文件（按序号排序）
2. 后显示该目录下的子目录（按序号排序）

### 4. 命名建议

| 内容类型 | 推荐前缀 | 示例 |
|---------|---------|------|
| 正文第一篇 | 01- | `01-internal-medicine/` |
| 正文第二篇 | 02- | `02-surgery/` |
| ... | ... | ... |
| 附录/术语表 | 99- | `99-glossary.md` |
| 参考文献 | 98- | `98-references.md` |

> 注：使用 90+ 序号可确保附录类内容始终显示在所有正文章节之后。
```

## 实施步骤

2. 执行 `npm run lint:markdown` 验证 Markdown 格式
3. 执行 `npm run docs:build` 验证构建正常
