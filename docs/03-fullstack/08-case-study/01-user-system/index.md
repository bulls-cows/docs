
# 用户管理系统

用户管理系统是后台管理系统的核心模块，提供用户信息管理、角色管理、权限控制等功能。本章将详细介绍用户系统的设计与实现。

## 系统概述

### 核心功能

- **用户列表管理**：分页查询、搜索、状态管理
- **角色管理**：角色定义、权限分配
- **权限控制**：路由权限、接口权限
- **认证授权**：登录认证、Token管理

### 角色体系

| 角色 | 标识 | 说明 |
|------|------|------|
| 超级管理员 | super_admin | 系统最高权限，不可修改 |
| 管理员 | admin | 后台管理权限 |
| VIP会员 | svip | 高级会员权限 |
| 会员 | vip | 普通会员权限 |
| 普通用户 | normal | 基础用户权限 |
| 游客 | guest | 未登录用户 |
