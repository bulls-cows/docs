
# 扩展功能

本章介绍系统的其他扩展功能模块，包括预约系统、导航系统、相册系统和日志监控。

## 章节导航

- [预约系统](./08-booking.md) - 在线预约功能设计
- [导航系统](./07-navigation.md) - 导航网站管理
- [相册系统](./09-album.md) - 相册和图片管理
- [日志监控](./10-monitoring.md) - 系统日志和错误监控

## 功能概览

| 功能模块 | 核心功能 | 适用场景 |
|---------|---------|---------|
| 预约系统 | 资源预约、时间管理 | 服务预约、场地预约 |
| 导航系统 | 网站收藏、分类管理 | 导航网站、书签管理 |
| 相册系统 | 图片上传、相册管理 | 图片展示、作品集 |
| 日志监控 | 错误追踪、性能监控 | 系统运维、问题排查 |
