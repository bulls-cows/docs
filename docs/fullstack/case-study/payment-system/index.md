
# 支付系统

支付系统是平台的核心功能之一，采用预付费余额模式，用户先充值到账户余额，然后在使用产品时按动作消耗余额。本章将详细介绍余额系统的设计与实现。

## 系统概述

### 设计思路

本系统采用**预付费余额模式**，主要优势：

1. **简化计费逻辑**：只需关注每个动作的费用和用户余额是否足够
2. **统一管理**：所有产品的计费都通过余额系统
3. **灵活扩展**：新增产品只需定义动作费用
4. **完整记录**：所有充值和消费记录都有完整的流水

### 交易类型

| 类型 | 标识 | 说明 |
|------|------|------|
| 充值 | recharge | 用户充值到余额 |
| 消费 | consume | 使用余额支付 |
| 退款 | refund | 消费退款/充值退款 |
| 调整 | adjust | 管理员手动调整 |
| 提现 | withdraw | 余额提现 |
