
# 内容管理系统

内容管理系统（CMS）是网站的核心模块，负责文章、分类、标签等内容的创建、编辑、发布和管理。本章将详细介绍内容管理系统的设计与实现。

## 系统概述

### 核心功能

- **文章管理**：文章创建、编辑、发布、删除
- **分类管理**：多级分类、分类排序
- **标签管理**：标签创建、文章标签关联
- **富文本编辑**：Markdown/富文本编辑器
- **付费阅读**：免费内容与付费内容分离

### 内容类型

| 类型 | 说明 |
|------|------|
| 免费内容 | 所有用户可见 |
| 付费内容 | 仅会员可见 |
| 草稿 | 未发布，仅作者可见 |
| 已发布 | 公开可见 |
