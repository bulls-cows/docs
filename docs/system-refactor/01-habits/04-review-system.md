
# 复盘系统

> "不复盘，无成长。" —— 复盘理念

## 什么是复盘

**复盘**源于围棋术语，指对局结束后重新演绎棋局，分析得失。应用到个人成长中，复盘是：

- 回顾过去的行为和结果
- 分析成功和失败的原因
- 提炼经验和教训
- 指导未来的行动

```text
复盘循环

行动 → 结果 → 反思 → 改进 → 行动
    │                        │
    └────────────────────────┘
```

## 复盘的价值

### 价值一：加速成长

**原理**：从经验中学习，避免重复犯错

```text
不复盘：
经历 → 遗忘 → 重复犯错

复盘：
经历 → 反思 → 提炼经验 → 避免犯错
```

### 价值二：清晰方向

**原理**：定期回顾，确保方向正确

- 目标是否还重要？
- 方法是否有效？
- 是否需要调整？

### 价值三：增强动力

**原理**：看到进步，增强信心

- 记录成就
- 看到成长
- 保持动力

## 复盘的层次

### 层次一：事件复盘

**时机**：完成一个任务或事件后

**内容**：

- 发生了什么？
- 结果如何？
- 原因是什么？
- 下次如何改进？

### 层次二：日复盘

**时机**：每天结束时

**内容**：

- 今天完成了什么？
- 有什么做得好的？
- 有什么需要改进的？
- 明天的计划是什么？

### 层次三：周复盘

**时机**：每周结束时

**内容**：

- 本周目标完成情况
- 重要进展和收获
- 遇到的问题和解决
- 下周计划和重点

### 层次四：月复盘

**时机**：每月结束时

**内容**：

- 月度目标完成情况
- 重要成就和里程碑
- 趋势和变化
- 下月计划和调整

### 层次五：年复盘

**时机**：每年结束时

**内容**：

- 年度目标完成情况
- 重大成就和遗憾
- 人生方向和价值观
- 来年规划和目标

## 复盘的方法

### 方法一：GRAI 复盘法

**步骤**：

1. **Goal（目标）**：回顾目标
2. **Result（结果）**：评估结果
3. **Analysis（分析）**：分析原因
4. **Insight（洞察）**：总结规律

### 方法二：KPT 复盘法

**步骤**：

1. **Keep（保持）**：做得好的，继续保持
2. **Problem（问题）**：存在的问题
3. **Try（尝试）**：下一步尝试的改进

### 方法三：PDCA 循环

**步骤**：

1. **Plan（计划）**：制定计划
2. **Do（执行）**：执行计划
3. **Check（检查）**：检查结果
4. **Act（处理）**：改进优化

## 复盘的习惯化

### 建立复盘习惯

**方法**：

- 固定时间复盘
- 绑定现有习惯
- 从简单开始

**建议**：

- 日复盘：睡前 10 分钟
- 周复盘：周日晚上 30 分钟
- 月复盘：每月最后一天 1 小时

### 复盘工具

| 工具 | 适用场景 |
|------|---------|
| 纸质笔记本 | 随手记录 |
| Notion | 结构化复盘 |
| Obsidian | 知识管理 |
| 飞书文档 | 团队复盘 |

## 复盘的常见问题

### 问题一：没时间复盘

**原因**：觉得复盘不重要

**解决**：

- 从 5 分钟开始
- 绑定现有习惯
- 感受复盘的价值

### 问题二：流于形式

**原因**：只是记录，没有思考

**解决**：

- 深入分析原因
- 提炼可行动的教训
- 跟踪改进效果

### 问题三：只看负面

**原因**：过度关注问题

**解决**：

- 同时记录成就
- 平衡正面和负面
- 肯定自己的进步

### 问题四：不复盘改进

**原因**：复盘后没有行动

**解决**：

- 复盘要有行动项
- 跟踪行动项执行
- 下次复盘回顾

## 团队复盘

### 团队复盘的价值

- 共享学习
- 统一认知
- 改进协作
- 建立文化

### 团队复盘的形式

| 形式 | 频率 | 时长 |
|------|------|------|
| 站会复盘 | 每日 | 15 分钟 |
| 迭代复盘 | 每两周 | 1 小时 |
| 项目复盘 | 项目结束 | 2 小时 |
| 季度复盘 | 每季度 | 半天 |

### 团队复盘的流程

1. **准备**：收集数据、准备材料
2. **回顾**：回顾目标和结果
3. **分析**：分析原因和问题
4. **改进**：制定改进措施
5. **跟进**：跟踪改进效果

1. **复盘价值**：加速成长、清晰方向、增强动力
