## 简介

本篇涵盖三甲医院中既不属于内科、外科，也不属于妇儿、五官的专科，包括皮肤科、肿瘤科、康复科、中医科、麻醉科、重症医学科、急诊科和精神科。这些专科各有独特价值，帮助读者全面了解医院各科室的职能与适用范围。

## 就医提示

这些专科各有特点，就医时可参考：

- 皮肤红斑、瘙痒、水疱长期不愈 → 皮肤科
- 肿瘤高危人群定期筛查、已确诊肿瘤治疗随访 → 肿瘤科
- 手术或脑卒中后功能恢复 → 康复科
- 持续情绪低落、失眠、焦虑无法自行调节 → 精神科
- 急症（胸痛、腹痛、出血、意识障碍）→ 急诊科
