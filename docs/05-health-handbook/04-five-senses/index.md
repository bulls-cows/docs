# 第四篇 五官 / 头颈系统

> **免责声明**：本手册内容仅供健康科普参考，不能替代专业医疗诊断和治疗。如有身体不适，请及时就医。

## 简介

五官/头颈系统涉及人体感觉器官和头颈部重要结构。本篇包括眼科、耳鼻喉科、口腔科和头颈外科四大专科，覆盖视力、听力、嗅觉、味觉及头颈部肿瘤等常见问题。

## 就医提示

五官/头颈疾病多以局部症状为主，就医时可参考以下指引：

- 视力下降、眼部不适 → 眼科
- 耳鸣、听力下降、鼻塞、咽痛 → 耳鼻喉科
- 牙痛、口腔溃疡 → 口腔科
- 颈部肿块、声音嘶哑进行性加重 → 头颈外科
