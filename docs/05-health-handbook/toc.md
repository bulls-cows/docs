# 目录

本手册以三甲医院临床专科体系为纲，共分六篇三十五章：

---

## 第一篇 内科系统

1. **第一章 心血管内科** — 高血压、冠心病、心绞痛、心梗、心律失常、心衰 ✅
2. **第二章 呼吸内科** — 感冒、流感、支气管炎、哮喘、肺炎、COPD ✅
3. **第三章 消化内科** — 胃炎、溃疡、GERD、消化不良、肠炎、便秘、胆结石、脂肪肝、痔疮 ✅
4. **第四章 内分泌科** — 糖尿病、甲亢、甲减、痛风、骨质疏松 ✅
5. **第五章 肾内科** — 急性肾炎、慢性肾炎、尿路感染、尿路结石 ⚠️
6. **第六章 血液内科** — 缺铁性贫血、再生障碍性贫血、血小板减少症 ⚠️
7. **第七章 风湿免疫科** — 类风湿关节炎、系统性红斑狼疮、干燥综合征 ⚠️
8. **第八章 感染科** — 病毒性肝炎、肺结核、细菌性痢疾、手足口病 ⚠️
9. **第九章 神经内科** — 偏头痛、失眠、焦虑抑郁、帕金森、脑卒中 ✅
