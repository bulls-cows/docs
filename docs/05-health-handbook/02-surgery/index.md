# 第二篇 外科系统

## 简介

外科系统涵盖人体多个解剖部位的外科疾病治疗。本篇包括普外科、骨科、神经外科、泌尿外科、心胸外科、血管外科、烧伤科和整形科八大专科，介绍各领域常见外科疾病的识别、手术时机和术后康复知识。

## 就医提示

外科疾病往往需要手术干预，但并非所有情况都需要急诊手术。以下情况建议及时外科就诊：

- 急性剧烈腹痛（尤其是伴有发热、呕吐）
- 外伤后疼痛剧烈、无法活动
- 体表发现迅速增大的肿块
- 排尿困难、尿痛伴发热
