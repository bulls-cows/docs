
# AI 辅助会议

> "高效的会议是团队协作的基石，AI 让会议更高效。" —— 佚名

## 概述

AI 辅助会议是利用人工智能工具优化会议全流程的过程，包括会前准备、会中记录、会后整理。通过 AI，可以自动生成会议议程、实时转录会议内容、智能生成会议纪要，大幅提升会议效率。

## 核心价值

| 传统会议 | AI 辅助会议 |
|----------|-------------|
| 手动整理议程 | AI 自动生成议程 |
| 人工记录易遗漏 | AI 实时转录记录 |
| 会后整理耗时长 | AI 自动生成纪要 |
| 待办事项易遗漏 | AI 自动提取任务 |
| 会议效率难评估 | AI 分析会议效果 |

## 主要应用场景

### 1. 会前准备

#### 会议议程生成

**场景**: 快速生成会议议程

**提示词模板**:

```markdown
请帮我生成会议议程：

会议主题：[主题]
会议目的：[目的]
参会人员：[人员/角色]
会议时长：[时长]

请生成：
1. 详细的议程安排
2. 每个议题的时间分配
3. 需要准备的材料
4. 预期产出

示例：
请帮我生成一个"产品迭代评审会"议程：
- 目的：评审Q4产品迭代计划
- 参会：产品经理、研发负责人、设计负责人
- 时长：1小时
```

**示例输出**:

```markdown
## 产品迭代评审会议程

### 会议信息
- **主题**：Q4产品迭代计划评审
- **时间**：2024年10月15日 14:00-15:00（1小时）
- **地点**：会议室A / 线上会议
- **参会人员**：产品经理、研发负责人、设计负责人、运营代表

### 议程安排

| 时间 | 议题 | 主讲人 | 时长 |
|------|------|--------|------|
| 14:00-14:05 | 开场与背景介绍 | 产品经理 | 5分钟 |
| 14:05-14:20 | Q4产品规划介绍 | 产品经理 | 15分钟 |
| 14:20-14:35 | 技术可行性评估 | 研发负责人 | 15分钟 |
| 14:35-14:45 | 设计方案讨论 | 设计负责人 | 10分钟 |
| 14:45-14:55 | 资源与排期确认 | 全体 | 10分钟 |
| 14:55-15:00 | 总结与下一步 | 产品经理 | 5分钟 |

### 需要准备的材料
- [ ] 产品规划文档（产品经理）
- [ ] 技术评估报告（研发负责人）
- [ ] 设计方案初稿（设计负责人）
- [ ] 运营数据报告（运营代表）

### 预期产出
1. 确认Q4产品迭代计划
2. 明确各团队任务分工
3. 确定关键里程碑节点
4. 识别潜在风险和应对措施

### 会前提醒
- 请各负责人提前准备相关材料
- 请提前10分钟到达会议室测试设备
- 如有议题需要补充，请提前告知
```

### 2. 会中记录

#### 实时转录

**场景**: 会议内容实时转录

**工具推荐**:

| 工具 | 特点 | 适用场景 |
|------|------|----------|
| 飞书妙记 | 中文识别优秀 | 企业会议 |
| 钉钉闪记 | 阿里生态集成 | 钉钉用户 |
| 腾讯会议 | 会议录制转录 | 腾讯生态 |
| Otter.ai | 英文识别优秀 | 国际会议 |
| 通义听悟 | 阿里AI转录 | 通用场景 |

**使用技巧**:

1. **会前准备**
   - 确认转录工具可用
   - 测试麦克风和音量
   - 开启录制和转录功能

2. **会中注意**
   - 发言清晰，语速适中
   - 重要内容重复强调
   - 提及发言人姓名便于区分

3. **会后处理**
   - 检查转录准确性
   - 标记关键内容
   - 删除无关内容

### 3. 会后整理

#### 会议纪要生成

**场景**: 快速生成会议纪要

**提示词模板**:

```markdown
请根据以下会议记录生成会议纪要：

会议主题：[主题]
时间：[时间]
参会人员：[人员]

会议内容：
[粘贴会议记录或转录]

要求：
1. 格式规范，结构清晰
2. 突出决议事项和待办任务
3. 标注责任人和完成时间
4. 语言简洁专业

示例：
请根据以下会议记录生成会议纪要：
会议主题：产品迭代评审会
时间：2024年10月15日
参会：张三（产品）、李四（研发）、王五（设计）
...
```

## 注意事项

### 适用场景

✅ **推荐使用**:

- 会议议程生成
- 会议纪要整理
- 待办事项提取
- 会议邀请撰写
- 跟进邮件生成

⚠️ **谨慎使用**:

- 敏感会议内容转录
- 涉及保密信息的会议
- 需要高度准确的正式记录

❌ **不建议使用**:

- 未经同意的会议录制
- 泄露商业机密
- 违反公司规定的操作

### 最佳实践

1. **会前准备充分**: 提前生成议程，发送会议邀请
2. **会中专注参与**: AI 记录，人专注讨论
3. **会后及时整理**: 24小时内发送会议纪要
4. **待办跟进到位**: 定期检查任务完成情况
5. **保护隐私安全**: 注意敏感信息的处理

### 常见问题

#### 1. 转录准确性不高

**解决方案**:

- 使用高质量麦克风
- 发言清晰，语速适中
- 选择适合语言的转录工具
- 会后人工校对关键内容

#### 2. 会议纪要太长

**解决方案**:

- 明确纪要模板和格式
- 突出决议和待办
- 删除无关内容
- 使用表格呈现关键信息

#### 3. 待办事项遗漏

**解决方案**:

- 会议结束前逐一确认
- 使用表格明确责任人和时间
- 设置提醒机制
- 定期跟进检查
