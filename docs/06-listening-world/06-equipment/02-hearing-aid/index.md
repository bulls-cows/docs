# 第二章 助听器

助听器（Hearing Aid）是通过电声学放大和数字信号处理，帮助听力损失者更清晰地听到声音的电子设备。与人工耳蜗依靠手术植入电极、直接刺激听神经不同，助听器是非侵入式设备，主要面向轻度至重度感音神经性听力损失、传导性听力损失或混合性听力损失人群，是世界卫生组织（WHO）推荐的听力康复首选干预手段之一[^1]。

现代助听器已从早期的简单放大装置发展为集多麦克风阵列、自适应降噪、人工智能场景识别和无线连接于一体的微型计算设备，单耳每天可处理数千万次的声音决策。
