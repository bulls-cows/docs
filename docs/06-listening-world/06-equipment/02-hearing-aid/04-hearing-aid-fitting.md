# 选配与验配流程

助听器并非"买回家就能戴"的消费品，而是需要专业验配师（Audiologist）按个人听力情况进行选型、参数调试、长期随访的医疗辅助设备。一次完整的验配通常包含 5 个阶段：评估 → 选型 → 验配 → 适应 → 随访。

## 一、验配前评估

在选择助听器之前，必须先获取一份完整的听力学评估报告，作为后续选型和编程的依据。

### 1. 基础听力检查

| 检查项 | 作用 |
|-------|------|
| **纯音测听（Pure Tone Audiometry）** | 测量气导和骨导听阈，绘制听力图，定位损失类型与程度 |
| **声导抗（Tympanometry）** | 评估中耳功能，排除中耳积液、咽鼓管功能障碍 |
| **言语测听（Speech Audiometry）** | 测量言语接受阈（SRT）和最大言语识别率（PB Max），评估言语理解能力 |
| **不舒适阈（UCL）** | 确定最大输出限值，避免助听器输出过响 |

### 2. 进阶评估（按需）

- **真耳分析（Real-Ear Measurement, REM）**：在耳道内放置探头麦克风，测量助听器实际输出，确保达到处方目标曲线，是国际公认的金标准
- **耳道镜检查**：排查耵聍栓塞、外耳道感染等
- **听性脑干反应（ABR）**：低龄儿童或不能配合行为测听者
- **认知与言语沟通需求评估**：了解日常用耳场景，作为程序设置参考

> 💡 **重要**：未经听力检查直接购买助听器，无法确定合适的增益和输出，长期使用可能造成"过放大"性二次损伤。世界听力组织和 NIDCD 均明确反对自行选购非验配设备[^1]。

## 二、选型决策

确定听力数据后，验配师会结合多个维度推荐合适的助听器类型。

| 决策维度 | 影响 |
|---------|------|
| **听力损失程度** | 极重度需大功率 BTE，轻度可选 RIC/CIC |
| **听力图构型** | 高频陡降型适合开放耳塞 RIC；平坦型适合标准耳模 |
| **生活场景** | 多噪声/会议多则需高端降噪；以居家为主可选中端 |
| **手部灵活度** | 老人选大按键 BTE，避免操作小巧的 CIC |
| **耳道条件** | 耳道狭窄、湿耳、慢性中耳炎不适合深耳道定制式 |
| **审美需求** | 隐蔽优先选 RIC / IIC，但需在性能上做妥协 |
| **预算范围** | 入门、中端、高端按通道数/降噪算法分级 |
| **是否需要无线** | 接打电话频繁可优先支持蓝牙直连的型号 |

可参考 [助听器分类](./02-hearing-aid-types.md) 了解各类型详细差异，参考 [主流品牌介绍](./03-hearing-aid-brands.md) 了解各品牌技术侧重。

## 三、验配过程

### 1. 试戴与初次编程

- **取耳样或选标准耳塞**：定制式与部分 RIC 需要取耳模印模
- **首次编程（First Fit）**：验配软件根据听力图与处方公式（NAL-NL2、DSL v5 等）自动生成初始增益
- **耳模与助听器组装**：完成物理装配
- **戴上试听**：用录音、对话、噪声等多种素材初步评估听感

### 2. 真耳分析（REM）

通过插入耳道的探头麦克风，测量助听器在用户真实耳道中的输出，对比目标曲线进行精细调整。这是确保实际增益符合处方的关键一步，国际听力学会推荐在每次配机和换机时都执行[^2]。

### 3. 主观感受微调

- 验配师与用户沟通"太响 / 太尖 / 闷 / 言语不清"等主观反馈
- 在多通道间调整增益、压缩比、降噪强度、方向性策略
- 设置 2-4 个不同场景程序（如安静、餐厅、音乐、电话）

## 四、适应期管理

助听器需要大脑重新学习处理新的声音输入，通常需要 1-3 个月的适应期。

### 推荐适应节奏

| 阶段 | 时间 | 佩戴建议 |
|------|------|---------|
| **第 1 周** | 安静家中佩戴 1-2 小时/天 | 适应自己声音和家中环境音 |
| **第 2 周** | 增加到 4-6 小时/天 | 加入对话、电视等场景 |
| **第 3-4 周** | 8 小时以上 | 加入超市、户外、聚会等复杂环境 |
| **1-3 个月** | 全天佩戴（除睡眠和洗澡） | 形成长期听觉重建 |

### 常见适应问题

- **自己声音听起来不自然（堵耳效应）**：可调整通气孔、OVP 算法
- **听到环境音过响（餐具碰撞、纸张声）**：1-2 周后大脑会自动适应；持续不适需调低高频增益
- **戴久了头晕**：通常源于过度放大或耳模阻塞，需复诊调整
- **新声音"听见但不懂"**：需要言语康复训练，与听觉重建并行

## 五、后期调试与随访

助听器是"动态适配"过程，不是"一次配机终身不变"。

### 推荐随访节奏

- **配机后 2 周**：第一次复诊，根据实际佩戴感受微调
- **配机后 1 个月**：第二次复诊，重点调整噪声场景表现
- **配机后 3 个月**：第三次复诊，确认全场景适应良好
- **此后每半年**：常规检查听力变化、清洁助听器、更新固件
- **每年**：复测纯音听力，必要时重新编程

部分高端品牌支持 **远程调试（Remote Fitting）**，可通过手机 APP 视频连接验配师调整参数，无需每次到店。

## 六、日常保养

良好的保养习惯能显著延长助听器寿命（一般为 5-8 年）。

| 保养项 | 频率 | 要点 |
|-------|------|------|
| **干燥** | 每晚 | 放入电子干燥盒或干燥饼盒，去除汗液与水汽 |
| **清洁** | 每天 | 用专用毛刷或软布清理耳塞、麦克风口；定期更换耳塞滤芯 |
| **检查耳模/耳塞** | 每周 | 检查是否有耳垢堵塞导声管，必要时清理或更换 |
| **更换电池** | 一次性电池约 5-10 天 | 充电式按厂商说明充电，避免完全放完电再充 |
| **避免高温** | 长期 | 不要放车内暴晒，不要使用吹风机直吹烘干 |
| **避免水浸** | 长期 | 洗澡、游泳、运动大汗时摘下，雨天加防护套 |
| **专业保养** | 每半年 | 到验配中心做超声波清洁、麦克风/受话器检测 |

## 七、何时应考虑升级或更换

出现以下情况时，应咨询验配师评估是否更换设备：

- 助听器使用 5-7 年以上，频繁故障
- 听力损失加重，现有助听器最大输出无法满足
- 已升级到言语识别仍不能满足沟通需求，需评估是否转向人工耳蜗
- 生活场景变化（如重返职场、社交需求增加）
