
# 第一章 康复基础

> **免责声明**：本手册内容仅供健康科普参考，不能替代专业医疗诊断和治疗。如有身体不适，请及时就医。

## 简介

语言康复训练是帮助听力障碍患者建立或重建听觉语言能力的过程。本章将介绍康复训练的基础知识，包括听觉训练的四个阶段、言语训练的主要内容，以及家庭康复的实用指导。

## 本章一览

| 节 | 名称 | 内容概述 |
|----|------|----------|
| 第一节 | 听觉训练 | 听觉察知、分辨、识别、理解四阶段训练方法 |
| 第二节 | 言语训练 | 发音训练、词汇积累、句子构建、交流能力培养 |
| 第三节 | 家庭康复指导 | 日常训练技巧、环境创设、注意事项 |
