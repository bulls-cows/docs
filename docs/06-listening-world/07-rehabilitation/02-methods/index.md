
# 第二章 康复方法

> **免责声明**：本手册内容仅供健康科普参考，不能替代专业医疗诊断和治疗。如有身体不适，请及时就医。

## 简介

本章介绍两种主要的语言康复方法：听觉口语疗法（AVT）和手语与替代沟通方式。不同的康复方法适合不同的患者群体，选择合适的方法需要综合考虑患者的听力状况、家庭意愿、康复目标等因素。

## 本章一览

| 节 | 名称 | 内容概述 |
|----|------|----------|
| 第一节 | 听觉口语疗法 | AVT 疗法的原理、适用对象、实施要点及家庭参与 |
| 第二节 | 手语与替代沟通 | 手语类型、学习建议及其他替代沟通方式介绍 |
