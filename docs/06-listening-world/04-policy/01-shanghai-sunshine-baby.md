# 上海"阳光宝宝卡"残疾儿童康复救助政策

> **重要提示**：本政策信息仅供参考，政策内容可能随时间发生调整，请以官方最新公告为准。建议在申请前咨询所在区残联或访问上海市残疾人联合会官网确认最新政策。

> **免责声明**：本手册内容仅供健康科普参考，不能替代专业医疗诊断和治疗。政策信息可能随时间变化，请以官方最新公告为准。如有身体不适，请及时就医。

## 政策背景和目的

"阳光宝宝卡"政策是上海市针对各类残疾儿童实施的重要民生保障政策。该政策旨在通过财政补贴的方式，减轻残疾儿童家庭的经济负担，确保每一位残疾儿童都能及时获得有效的康复服务。

**政策出台背景**：

- 残疾是儿童常见的出生缺陷或发育障碍之一
- 早期干预对残疾儿童的康复和发育至关重要
- 康复训练需要长期持续投入，经济压力较大
- 体现社会对残疾儿童的关怀和保障

**政策目标**：

- 实现残疾儿童"早发现、早干预、早康复"
- 降低残疾儿童家庭的经济负担
- 提高残疾儿童的康复效果和生活质量
- 促进残疾儿童融入社会

## 阳光宝宝卡

### 卡类别

阳光宝宝卡根据残疾类型分为7种类别：

| 类别 | 适用对象 |
|------|---------|
| 视力类 | 视力障碍儿童 |
| 听力类 | 听力障碍儿童 |
| 言语类 | 言语障碍儿童 |
| 肢体类 | 肢体障碍儿童（不含脑瘫） |
| 脑瘫类 | 脑瘫儿童 |
| 智力类 | 智力障碍儿童 |
| 孤独症类 | 孤独症谱系障碍儿童 |

### 申请路径

**方式一：现场申请**

1. 携带相关材料到户籍所在区残联窗口办理
2. 填写《上海市阳光宝宝卡申请表》
3. 提交相关证明材料
4. 等待审核（一般15个工作日内）
5. 审核通过后领取阳光宝宝卡

**方式二：一网通办线上申请**

1. 登录"一网通办"平台（<https://zwdt.sh.gov.cn）>
2. 搜索"阳光宝宝卡"申请事项
3. 在线填写申请表单
4. 上传相关证明材料电子版
5. 提交申请并等待审核
6. 审核通过后，可选择邮寄或现场领取阳光宝宝卡

### 生效时间

- 阳光宝宝卡自审核通过之日起生效
- 有效期至儿童年满18周岁
- 每年需进行资格复核

### 注销流程

1. 儿童年满18周岁自动注销
2. 儿童户籍迁出本市的，需到原发证区残联办理注销手续
3. 儿童康复情况改善不再符合救助条件的，由区残联审核后注销
4. 持卡人或监护人主动申请注销的，可到区残联办理

### 户口迁移

- 儿童在本市内迁移户口的，需到原户籍所在区残联办理转出手续
- 到新户籍所在区残联办理转入手续
- 阳光宝宝卡继续有效，无需重新申请
- 补贴待遇从转入次月起由新户籍所在区承担

### 遗失补办

1. 阳光宝宝卡遗失的，监护人可向区残联申请补办
2. 需提供儿童户口簿、监护人身份证等材料
3. 补办期间不影响救助待遇享受
4. 一般7个工作日内完成补办

### 信息变更

- 儿童或监护人信息发生变更的，应及时到区残联办理更新
- 包括：姓名、身份证号、联系电话、住址等
- 变更后需重新打印阳光宝宝卡

## 救助对象和条件

> **重要提示**：以下申请条件为当前执行标准，具体以官方最新公告为准。

### 基本条件

申请阳光宝宝卡康复救助需同时满足以下条件：

1. **户籍要求**：具有上海市户籍
2. **年龄要求**：未满18周岁
3. **资质证明**：持有以下任一证明：
   - 《中华人民共和国残疾人证》
   - 三级以上医院出具的孤独症诊断证明
   - 阳光宝宝卡（有效期内）

### 各类型具体条件

**视力类**：

- 经专业医疗机构确诊为视力障碍
- 符合视力残疾标准或存在视力功能障碍

**听力/言语类**：

- 经专业医疗机构确诊为听力障碍或言语障碍
- 符合听力/言语残疾标准或存在听力/言语功能障碍

**肢体类**：

- 经专业医疗机构确诊为肢体障碍（不含脑瘫）
- 符合肢体残疾标准或存在肢体功能障碍

**脑瘫类**：

- 经专业医疗机构确诊为脑性瘫痪
- 需要进行系统康复训练

**智力类**：

- 经专业医疗机构确诊为智力障碍
- 符合智力残疾标准或存在智力发育迟缓

**孤独症类**：

- 经三级以上医院确诊为孤独症谱系障碍
- 需要进行系统康复训练

## 补贴标准和范围

> **重要提示**：补贴标准可能根据政策调整而变化，具体以官方最新公告为准。

### 补贴标准

| 救助类别 | 年度补贴限额 | 备注 |
|----------|-------------|------|
| 视力类 | 10000元/人/年 | 视力网络训练报销限额50% |
| 听力类 | 10000元/人/年 | |
| 言语类 | 10000元/人/年 | |
| 智力类 | 10000元/人/年 | |
| 肢体类 | 15000元/人/年 | 不含脑瘫 |
| 肢体（脑瘫）类 | 24000元/人/年 | |
| 孤独症类 | 24000元/人/年 | |

### 费用范围

**可报销费用**：

- 医保报销后个人负担的康复训练费
- 在定点康复机构发生的符合规定的康复训练费用

**不予报销费用**：

- 挂号费
- 评估费
- 检查费
- 配药费
- 手术费
- 住院费
- 辅助器具费
- 其他非康复训练费用

## 康复服务机构

### 机构选择

- 救助对象可**自主选择**本市定点康复服务机构
- 可同时选择多家定点机构接受服务
- 建议选择离家近、交通便利的机构

### 机构定义和范围

定点康复服务机构包括：

1. 医疗机构类：具有医疗资质的康复机构
2. 非医疗机构类：经残联认定的康复服务机构

### 非医疗机构开票要求

非医疗机构类定点机构应：

- 开具正规增值税普通发票
- 发票内容注明"康复训练费"
- 加盖机构发票专用章
- 提供费用明细清单

### 记录上传要求

定点康复机构应：

- 如实记录救助对象的康复训练情况
- 及时将康复训练记录上传至残联管理系统
- 保存康复训练档案至少3年
- 配合残联的监督检查

## 申请流程

> **重要提示**：申请流程可能根据政策调整而变化，具体以官方最新公告为准。

### 时间节点

**救助年度**：上一年10月1日至当年9月30日

**集中申请时间**：

- 春季：4月
- 秋季：10月

**年度截止日期**：10月31日（申请上一救助年度补贴）

**就高原则**：如符合多项救助条件，按最高补贴标准执行，不重复享受

### 申请材料清单

**基础材料**：

1. 儿童户口簿原件及复印件
2. 监护人身份证原件及复印件
3. 儿童近期免冠1寸照片2张
4. 阳光宝宝卡原件及复印件

**资质证明材料**（三选一）：

1. 《中华人民共和国残疾人证》原件及复印件
2. 三级以上医院出具的孤独症诊断证明原件
3. 其他相关残疾诊断证明

**费用材料**：

1. 康复训练费用发票原件
2. 费用明细清单
3. 康复训练记录证明

### 申请流程说明

**第一步：确诊和评估**

- 到指定医院进行相关检查和诊断
- 获得正式的诊断证明或办理残疾人证

**第二步：办理阳光宝宝卡**

- 向户籍所在区残联申请办理阳光宝宝卡
- 提交相关证明材料
- 等待审核通过后领取阳光宝宝卡

**第三步：选择康复机构并接受训练**

- 在定点康复机构名单中选择合适的机构
- 与机构沟通，制定康复训练方案
- 按计划接受康复训练

**第四步：提交补贴申请**

- 在集中申请期内（4月或10月）向区残联提交申请
- 填写《上海市残疾儿童康复救助补贴申请表》
- 提交全部申请材料

**第五步：审核和拨付**

- 区残联审核申请材料
- 审核通过后按规定拨付补贴资金
- 补贴资金一般直接拨付至监护人银行账户

**第六步：年度复核**

- 每年进行一次资格复核
- 根据康复情况调整救助方案

> **提示**：建议申请前先咨询所在区残联，了解最新的政策要求和办理流程。

## 办理地点和联系方式

### 查询最新联系方式

各区残疾人联合会（残联）的具体地址和联系电话可能随时间变化，建议通过以下方式获取最新信息：

1. **访问上海市残疾人联合会官网**：[http://www.shdpf.org.cn](http://www.shdpf.org.cn)
2. **拨打全国统一服务热线**：12385（残疾人服务热线）
3. **查询各区政府官方网站**：搜索"XX区残疾人联合会"获取最新联系方式

### 办理流程提示

- 申请需向**户籍所在区残联**提交材料
- 建议办理前先通过官网或电话确认最新政策和办理要求
- 市级主管部门：上海市残疾人联合会

## 注意事项

1. **诚信原则**：申请材料必须真实有效，弄虚作假将取消救助资格，并依法追回已领取的补贴资金，情节严重的将依法追究法律责任。

2. **发票退费处理**：如已申请补贴的发票发生退费，应及时向区残联报告，并按规定退回相应的补贴资金。

3. **政策时效性**：补贴标准和申请条件可能会根据实际情况调整，请及时关注官方公告。

4. **定点机构要求**：必须在定点康复机构接受服务，否则无法享受补贴。

5. **申请时限**：请在规定的申请期内提交申请，逾期将影响补贴享受。上一救助年度的费用申请截止日期为当年10月31日。

6. **持续康复**：获得补贴后应坚持康复训练，定期接受评估，确保康复效果。

7. **跨区办理**：一般应在户籍所在区办理，特殊情况可咨询市残联。

如需了解更详细的政策信息，建议直接联系所在区残联或访问上海市残疾人联合会官网查询最新公告。

## 政策实施效果和意义

### 实施成效

**覆盖面广**：

- 政策实施以来，已惠及数万名残疾儿童
- 实现了上海市户籍残疾儿童的全覆盖
- 补贴标准逐年提高，保障水平不断提升

**康复效果显著**：

- 残疾儿童接受康复训练的平均年龄大幅降低
- 康复率明显提高
- 大部分康复儿童能够进入普通学校就读

**家庭负担减轻**：

- 累计补贴金额超亿元
- 平均每个家庭减少支出数十万元
- 有效缓解了因病致贫、因病返贫问题

### 政策意义

**民生保障的重要举措**：

- 体现了政府对残疾儿童的关怀
- 是社会公平正义的具体体现
- 彰显了城市温度和文明程度

**促进社会和谐发展**：

- 帮助残疾儿童融入主流社会
- 减少家庭和社会的长期负担
- 创造更加包容的社会环境

**示范引领作用**：

- 上海"阳光宝宝卡"政策在全国处于领先水平
- 为其他地区提供了可复制的经验
- 推动了全国残疾儿童康复救助事业的发展
