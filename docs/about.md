# 关于牛牛文档

## 我们是谁

**牛牛文档**（docs.verysites.com）是由**牛牛团队**创建和维护的技术知识库与产品文档站。

牛牛团队是一支小型技术团队，由**滕先生**和**黄女士**两名成员组成。我们拥有 15 年生物与信息技术交叉领域的从业经验，致力于将专业知识转化为易于理解的内容，帮助更多人提升技能、解决问题。

## 这个站点是什么

牛牛文档是一个**技术知识库与产品文档结合**的平台，我们在这里发布：

- **原创技术书籍**：涵盖 AI 应用、编程开发、认知提升等主题
- **产品使用文档**：帮助用户更好地使用我们在 [www.verysites.com](https://www.verysites.com) 上发布的产品

无论你是开发者、AI 爱好者，还是希望提升工作效率的互联网用户，都能在这里找到有价值的内容。

## 我们的内容

目前，牛牛文档提供以下四本原创书籍：

| 书籍 | 简介 |
| --- | --- |
| [AI 辅助工作指南](/vibe-working/) | 让 AI 成为你的智能助手，从文档处理到科研工作，全面提升日常工作效率 |
| [AI 辅助编程指南](/vibe-coding/) | 用自然语言描述需求，让 AI 帮你写代码。从需求到实现，编程从未如此简单 |
| [Web 全栈开发指南](/fullstack/) | 汇集牛牛团队 TypeScript 全栈开发的最佳实践，涵盖前后端开发、架构设计等核心内容 |
| [重构你的系统](/system-refactor/) | 重塑认知体系，提升搜索、科研、技能运用能力。帮助你在瓶颈期找到突破口，实现自我进化 |
